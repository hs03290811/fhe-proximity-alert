# 합성 GPS 기반 근접 경보 프로토타입 소프트웨어 기능명세서

## 사용자가 다루는 화면과 파일

관제 담당자는 시나리오를 선택하여 두 GPS 파일의 시간 흐름을 재생한다. 피해자 노드는 별도의 C++ 실행 프로그램으로 파일을 읽고 1km 위치 공개 플래그를 복호화한다. 가해자 노드 위치는 파일에서 공급한다. 서버는 피해자 평문 위치를 수신한 프레임의 100m 긴급 여부를 판정하고 관제 화면에 표시한다. [팀 2 제안서 6–8쪽](../보안프로젝트설계_Team2_proposal.pdf#page=6)

## 기능 요구사항

| ID | 기능 | 동작과 확인 기준 |
| --- | --- | --- |
| F-01 | 경로 생성용 좌표 입력 | 두 노드의 출발·도착점과 필요한 경유점을 지도에서 지정하거나 좌표열 파일을 불러온다. 정지 노드는 한 점을 사용한다. 경로 제공자가 반환한 순서대로 좌표열을 저장할 수 있는 데이터 출처를 사용한다. |
| F-02 | 합성 GPS 파일 생성 | 실행 설정대로 경로를 시간별로 보간한다. 설정한 시드와 노이즈를 적용하여 노드별 관측 CSV와 검증용 참값 CSV를 생성한다. 무잡음 설정에서는 관측값과 참값이 좌표 변환의 허용 오차 범위 안에서 일치한다. |
| F-03 | 시나리오 선택과 재생 | 관제 담당자가 시나리오를 선택하고 재생·일시정지·처음부터 재생을 할 수 있다. 같은 시각의 두 좌표를 한 프레임으로 평가하고 관제에 현재 재생 시각을 표시한다. |
| F-04 | 가해자 평문 위치 입력 | 가해자 파일의 현재 행을 평문으로 중앙 서버에 제공한다. 화면에서 현재 프레임의 가해자 위치를 확인할 수 있다. |
| F-05 | 피해자 관측 위치 암호화 | C++ 피해자 노드가 피해자 파일에서 해당 프레임의 위치를 읽고 격자화한 뒤 암호문을 보낸다. 관제 화면은 F-07 절차를 통해 공개된 피해자 좌표만 표시한다. |
| F-06 | 1km 위치 공개의 암호화 판정 | 서버가 암호화된 격자 제곱거리를 1km 임계값과 비교해 암호화된 위치 공개 플래그를 반환한다. 경계값을 포함한다. |
| F-07 | 플래그 복호화 및 위치 공개 | 피해자 노드가 1km 위치 공개 플래그를 복호화한다. 1km 초과이면 위치를 보내지 않는다. 1km 이내이면 해당 프레임의 시각과 관측 좌표를 평문으로 서버에 보낸다. |
| F-08 | 100m 긴급 판정과 관제 단계 표시 | 1km 초과는 **평상시 감시**, 1km 이하는 **1km 대응**으로 표시한다. 서버가 그 프레임의 피해자 위치를 받으면, 같은 시각의 두 평문 관측 좌표를 격자화해 100m 이하인지 판정한다. 100m 이하이면 **긴급**을 표시한다. 공개된 좌표와 시각을 표시한다. |
| F-09 | 검증 결과 확인 | 같은 격자 입력의 평문 기준값과 1km 복호화 결과를 비교하고, 위치를 공개한 프레임의 100m 서버 판정도 평문 기준값과 비교한다. 참거리 기준과의 차이를 별도로 확인한다. 참값 파일은 관제 재생 입력에서 분리한다. |
| F-10 | 1km 진입 대응 시연 | 1km 밖에서 안으로 들어온 프레임에서 **경찰 → 피해자**, **보호관찰관 → 가해자**를 화면에 표시한다. 실제 기관 연계 범위와 방식은 미정이다. |

## 관제 화면에서 보여줄 정보

| 영역 | 내용 |
| --- | --- |
| 재생 조작 | 시나리오 이름, 재생·일시정지·처음부터, 입력 시각과 완료된 평가 프레임 |
| 지도 | 가해자 현재 위치. 1km 이내이면 피해자 노드가 준 위치를 해당 시각과 함께 표시한다. 과거에 수신한 위치를 보여줄 때는 해당 수신 시각으로 표시한다. |
| 단계 및 처리 내역 | 현재 단계, 평가 진행·완료, 피해자 위치 수신 여부와 시각, 1km 진입 대응 방향과 100m 긴급 표시, 평가 소요 시간 |
| 실험 결과 | 관제 화면과 분리된 검증 표 또는 그래프. 참거리 곡선과 1km·100m 기준선, 평문 기준값, 1km 복호화 결과와 100m 서버 판정을 표시한다. |

1km 밖에서는 해당 시각의 피해자 위치를 새로 수신하거나 현재 위치로 표시하지 않는다. 화면에 과거 수신 기록을 보여줄 때는 그때의 수신 시각을 함께 표시한다. 결과 확인에 실패한 프레임은 평상시 감시와 구분한다.

## 시연 인수 항목

1. 격자 거리 기준으로 모든 시각에 1km를 초과하는 입력에서는 평상시 감시가 유지되고, 피해자 위치 수신과 100m 긴급 판정이 발생하지 않는다.
2. 격자 거리 기준으로 1km 밖에서 움직이다가 정확히 1km에 이르면 해당 프레임의 피해자 위치가 수신되고 두 대응 방향이 표시된다.
3. 서버는 피해자 위치를 받으면 해당 프레임의 평문 격자 거리로 긴급 여부를 결정한다. 정확히 100m이면 긴급을 표시하고, 100m를 초과하고 1km 이내이면 1km 대응을 표시한다.
4. 두 경계를 순서대로 통과하는 입력에서는 **평상시 감시 → 1km 대응 → 긴급 표시** 순으로 표시된다. 1km 밖에서 바로 100m 이내로 진입하면 피해자 위치를 받은 프레임에 두 대응 방향과 긴급을 함께 표시한다.
5. 노이즈 실험에서는 동일한 격자 입력의 평문 기준값으로 1km 복호화 결과와 위치를 공개한 프레임의 100m 서버 판정을 검증한다. 참거리 기준과 다른 프레임은 별도로 집계한다. 동일한 파일을 다시 재생하면 판정과 위치 수신 여부가 재현된다.
